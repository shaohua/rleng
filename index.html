RL for engineers who ship agents.

Short recipes that take you from evaluating an agent to training a small model with GRPO against a reward you designed. Every recipe has a pass/fail your coding agent can check.

uv tool install git+https://github.com/shaohua/rleng
rleng list
rleng get eval-an-agent && cd eval-an-agent
rleng run       # PASS / FAIL with hints
rleng inspect   # read the actual outputs

The path

1

Evaluate an agent (and your evaluator)

Score two tool-using agents with a programmatic verifier, and measure the verifier against ground truth.

  • CPU only
  • ~10m
  • verified: any laptop
  • 8/8 unaided agent runs pass
rleng get eval-an-agent
2

Design a reward that can't be gamed

Fix a plausible-looking reward until an optimizer can no longer cheat it.

  • CPU only
  • ~15m
  • verified: any laptop
  • 8/8 unaided agent runs pass
rleng get design-a-reward
4

Your first GRPO run

Train a tiny model with GRPO + LoRA to emit correct tool calls, scored by the reward you designed in recipe 2.

  • GPU · 8 GB+
  • ~15m
  • verified: apple-m1-pro-16gb
  • 2/2 unaided agent runs pass
rleng get first-grpo

Why this exists

  • Verified, not aspirational. rleng verify checks real metrics. Hardware badges come from real runs.
  • Agent-first. Stable CLI, JSON output, an AGENT.md per recipe, and a measured pass rate for unaided coding agents.
  • Inspect, don't just plot. Every recipe ends with reading real outputs.
For theory: hands-on-modern-rl. For fast fine-tuning notebooks: Unsloth. rleng is the practical bridge. · GitHub
